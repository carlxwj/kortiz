# Présenter Kortiz pour une candidature en informatique

## Compétences que ce projet peut illustrer

- **Modélisation** : utilisateurs, groupes, participants, dépenses, soldes, invitations, conversations.
- **Algorithmique** : répartitions, calculs déterministes, arrondis, contrôles des montants et états.
- **Développement web** : HTML, CSS, JavaScript, interface responsive, traductions.
- **Backend et sécurité** : Functions Firebase, règles d'autorisation, séparation client/serveur.
- **Qualité** : tests de régression, recherche de bugs, prise en compte du fonctionnement mobile.
- **Conception produit** : conception d'une application à besoin concret, protections des données, amélioration continue.

## Comment expliquer une contribution personnelle

Décrire un problème résolu et **montrer le code que l'on comprend réellement**, avec un exemple vérifiable. Par exemple : « J'ai travaillé sur la logique de répartitions d'une dépense, puis écrit/vérifié des tests pour les cas limites ». Ne pas attribuer à soi seul tout le code généré par des assistants ; préciser l'aide reçue si elle est pertinente.

## Trois démonstrations utiles

1. Schéma des données d'un groupe et justification des règles d'accès.
2. Simulation de partage d'une dépense avec vérification de l'invariant de somme.
3. Scénario de sécurité : un membre hors groupe tente de consulter un document privé et l'accès est refusé.

## Proposition de texte pour portfolio

> Kortiz est un projet personnel d'application web pour gérer des dépenses communes et suivre des demandes de remboursement, sans transfert d'argent intégré. Le projet m'a permis d'explorer la conception d'interfaces, la modélisation de données, les autorisations et les tests de régression. Je poursuis son amélioration et ses validations en conditions réelles.
